Aetheria uses the following third-party assets. All art/audio used at runtime is either original
(procedural code) or CC0/OFL.

## Engine

- **Godot Engine 4.7.2** — MIT License
  https://godotengine.org/license

## UI assets — Kenney

- **Kenney UI Pack** — CC0 1.0 Universal
  https://kenney.nl/assets/ui-pack
  Used: interface sound files, theme inspiration. (The game's icons are original SVG paths;
  the Kenney UI pack was evaluated and its sounds are used.)
- **Kenney Interface Sounds** — CC0 1.0 Universal
  https://kenney.nl/assets/interface-sounds
  Used: `click.ogg`, `confirm.ogg`, `error.ogg`, `back.ogg`, `drop.ogg`, `bong.ogg`.
  License text: `game/assets/sfx/KENNEY_LICENSE.txt`.
