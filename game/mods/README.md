# Mods

Эта папка предназначена для аддитивных модов. Содержимое модов здесь
**не хранится в репозитории**: `.gitignore` разрешает только этот README.

Кладите моды в:

- `game/mods/<имя_мода>/` — при запуске из проекта;
- `%APPDATA%\Godot\app_userdata\Aetheria\mods\<имя_мода>\` — для установленной игры;
- `<папка Aetheria.exe>/mods/<имя_мода>/` — портативно.

Структура:

```
<мод>/
  mod.gd          # необязательно; extends Node, func setup(game)
  data/*.json     # необязательно; оверлей данных по id
  assets/         # новые ассеты
```

Можно добавлять **новые файлы и новые функции**. Нельзя изменять,
удалять или перезаписывать существующие файлы игры и критически ломать
базовую сборку. Подробности — в корневых `MODDING.md` и `CODE_POLICY.md`.
