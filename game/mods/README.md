# Mods

Эта папка предназначена для модов, но **содержимое модов здесь не хранится**
в репозитории: `.gitignore` разрешает только этот README.

Кладите моды в:

- `game/mods/<имя_мода>/data/*.json` — при запуске из проекта;
- `%APPDATA%\Godot\app_userdata\Aetheria\mods\<имя_мода>\data\` — для установленной игры;
- `<папка Aetheria.exe>/mods/<имя_мода>/data/` — портативно.

Подробности и пример — в корневом `MODDING.md` и `CODE_POLICY.md`.

Помните: основные файлы игры изменять нельзя. Мод — только отдельный слой данных.
