AETHERIA — готовый билд
======================

Запуск:
  Aetheria.cmd
или:
  Aetheria.exe --main-pack Aetheria.pck

Aetheria.exe — runtime Godot 4.7.2, Aetheria.pck — ресурсы игры.
Папку можно переносить целиком. Сохранения лежат в
%APPDATA%\Godot\app_userdata\Aetheria\saves
(внутри игры: «Сохранить» / «Загрузить»).

Управление:
  WASD / ПКМ — панорама, Q/E / СКМ — поворот, колесо — зум
  ЛКМ — применить силу, Пробел — пауза, 1–5 — скорость
  Tab — правая панель, H — скрыть интерфейс, F1 — помощь
  Ctrl+Z / Ctrl+Y — отмена/повтор рельефа, F12 — скриншот, F11 — полный экран

Подробности — в ..\README.md и ..\docs\10_IMPLEMENTATION.md.
