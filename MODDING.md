# Aetheria — моды поверх игры

Политика проекта разрешает **только моды-надстройки**. Основные файлы
(`game/scripts`, `game/data`, `game/scenes`, `game/assets`) менять нельзя.

## Куда класть мод

Поддерживаются три расположения:

| Среда | Путь |
|---|---|
| рядом с игрой (портативно) | `<папка Aetheria.exe>/mods/<имя_мода>/data/` |
| пользовательская папка Godot | `%APPDATA%\Godot\app_userdata\Aetheria\mods\<имя_мода>\data\` |
| разработка | `game/mods/<имя_мода>/data/` (папка игнорируется Git) |

## Структура

```
mods/
  my_mod/
    README.md           (необязательно)
    data/
      races.json        (необязательно)
      animals.json      (необязательно)
      buildings.json    (необязательно)
      techs.json        (необязательно)
      powers.json       (необязательно)
      biomes.json       (необязательно)
      eras.json         (необязательно)
```

Файлы — обычные JSON-массивы той же схемы, что и в `game/data/`.
Загрузчик `DataStore` объединяет записи по `id` (у эпох — по `name`):
поля мода переопределяют базовые, новые объекты добавляются.

## Пример: новая технология

`mods/my_mod/data/techs.json`

```json
[
  {
    "id": "steam_armor",
    "era": 5,
    "name": "Паровые доспехи",
    "name_en": "Steam Armor",
    "cost": 13500,
    "desc": "Экспериментальная броня мастерской. Даёт преимущество в бою.",
    "desc_en": "Experimental workshop armor. Grants a combat advantage.",
    "mods": { "military": 0.15, "prod": 0.05 }
  }
]
```

## Пример: изменить расу

`mods/my_mod/data/races.json`

```json
[
  {
    "id": "human",
    "name": "Люди",
    "name_en": "Humans",
    "hp": 105,
    "fertility": 1.05
  }
]
```

## Ограничения

- Нельзя добавлять новые **скрипты**, сцены или шейдеры — только данные.
- Нельзя заменять `project.godot`, `game/scripts/**`, `game/scenes/**`,
  `game/assets/**`, `build/**`.
- Мод не должен содержать файлы базовой игры.
- Некорректный JSON пропускается; игра продолжает работать.
- Совместимость с будущими версиями не гарантируется.

## Проверка

Запустите игру, откройте консоль (в dev-сборке) — при загрузке будет строка
`[D] mods: my_mod`. В интерфейсе изменения появятся в кодексе/дереве технологий,
если мод меняет соответствующие данные.
