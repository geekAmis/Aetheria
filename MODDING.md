# Aetheria — моды поверх игры

Политика проекта разрешает **добавлять новые файлы и новые функции**, но
запрещает изменять существующие основные файлы. Мод не должен критически
ломать базовую сборку.

## Куда класть мод

Поддерживаются три расположения:

| Среда | Путь |
|---|---|
| рядом с игрой (портативно) | `<папка Aetheria.exe>/mods/<имя_мода>/` |
| пользовательская папка Godot | `%APPDATA%\Godot\app_userdata\Aetheria\mods\<имя_мода>\` |
| разработка | `game/mods/<имя_мода>/` |

## Структура

```
mods/
  my_mod/
    mod.gd              # необязательно; точка входа новых функций
    README.md           # необязательно
    data/
      races.json        # необязательно
      animals.json      # необязательно
      buildings.json    # необязательно
      techs.json        # необязательно
      powers.json       # необязательно
      biomes.json       # необязательно
      eras.json         # необязательно
    assets/             # новые ассеты Мода
```

## 1. Данные (JSON-оверлей)

Файлы — обычные JSON-массивы той же схемы, что и в `game/data/`.
Загрузчик `DataStore` объединяет записи по `id` (у эпох — по `name`):
поля мода переопределяют базовые, новые объекты добавляются.

### Новая технология

`mods/my_mod/data/techs.json`

```json
[
  {
    "id": "steam_armor",
    "era": 5,
    "name": "Паровые доспехи",
    "name_en": "Steam Armor",
    "cost": 13500,
    "desc": "Экспериментальная броня мастерской. Даёт преимущество в бою.",
    "desc_en": "Experimental workshop armor. Grants a combat advantage.",
    "mods": { "military": 0.15, "prod": 0.05 }
  }
]
```

### Изменить расу

`mods/my_mod/data/races.json`

```json
[
  {
    "id": "human",
    "name": "Люди",
    "name_en": "Humans",
    "hp": 105,
    "fertility": 1.05
  }
]
```

## 2. Новые функции: `mod.gd`

Можно добавлять новые скрипты, UI, системы и узлы. Точка входа — новый файл
`mods/my_mod/mod.gd`, который не изменяет ядро.

```gdscript
extends Node

func setup(game) -> void:
    game.hud.toast("Мой мод загружен", "tech")
    # game.world, game.sim, game.hud, game.camera_rig доступны
```

Загрузчик:
- компилирует `mod.gd`;
- добавляет экземпляр в дерево игры;
- вызывает `setup(game)`, если функция есть;
- пропускает некомпилируемые моды с предупреждением, не ломая базовую игру.

Мод может:
- добавлять новые сцены/узлы как дочерние;
- подключаться к сигналам `game.sim`;
- создавать новые панели и окна;
- регистрировать свои данные и использовать их;
- расширять поведение через новые системы.

Мод **не может**:
- изменять/удалять/перезаписывать существующие файлы;
- подменять ядро;
- требовать правки ядра;
- делать базовую игру неспособной запуститься без Мода;
- повреждать сохранения базовой игры.

## 3. Новые ассеты

Кладите новые текстуры/звуки/модели в `mods/my_mod/assets/`. Не заменяйте
файлы из `game/assets/`. Загружайте их из своего `mod.gd` по пути
`res://mods/my_mod/assets/...` (в проекте) или через абсолютный путь
рядом с `.exe`.

## 4. Проверка

Запустите игру — при загрузке в консоли появится:

```
[D] mods: my_mod
[Mods] scripts: my_mod
```

Если мод сломан, удалите его папку: базовая игра должна запускаться без него.
Совместимость с будущими версиями не гарантируется.
