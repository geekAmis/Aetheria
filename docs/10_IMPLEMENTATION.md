## 2. Архитектура

```
Main (меню, загрузка, смена сессий)
 └── GameSession (связующий контроллер)
      ├── WorldModel  (данные мира, детерминированная генерация)
      ├── SimWorld    (симуляция; не знает о рендере)
      ├── CameraRig / TerrainView / NatureView / SettlementView / CreatureView / FXView / SkyView
      └── HUD (CanvasLayer)
```

`WorldModel` и `SimWorld` общаются с рендером через сигналы (`terrain_changed`, `agent_spawned`,
`effect`, `chronicle_added`, `era_changed`, ...). Все контентные данные лежат в `game/data/*.json`.
Все случайности — seeded `RandomNumberGenerator`; мир воспроизводим по seed.

## 3. Производительность

- 256×256: 64 чанка рельефа + 64 водных; 8–15 тыс. деревьев/камней в MultiMesh.
- 80–250 существ, 16–26 зданий на поселение, 6–8 поселений: ~100 FPS на RTX 4060 при 20×.
- Симуляция дня ~10–15 мс GDScript при 200 существах; рендер и UI — отдельно.
- Оптимизации: кэш плодородия биомов, группировка агентов по поселениям, кэш воды поселения,
  LOD-агенты, MultiMesh, чанковые меши, отложенная пересборка природы/миникарты, bulk-режим
  для тестовых прогонов.

## 4. Отличия от полного ТЗ

- Вместо 10 000 существ — 250–1000 (зависит от сценария), чтобы сохранить 60 FPS на GDScript.
- 7 рас, 24 животных, 22 здания, 48 технологий, 46 сил — вертикальный срез, а не весь контент.
- Мультиплеер, мастерская Steam, полная озвучка, 11 языков — вне текущего объёма.
- Английский язык покрывает данные и основные строки, но не все динамические тексты.
