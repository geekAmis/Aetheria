## 2. Архитектура

```
┌─────────────────────────────────────────────────────────┐
│                        UI / HUD                         │
├─────────────────────────────────────────────────────────┤
│                    Presentation (Render)                │
│  камера · меши чанков · инстансы · партиклы · звук      │
├─────────────────────────────────────────────────────────┤
│                  Simulation (Deterministic)             │
│  время · мир · существа · бой · экономика · политика    │
├─────────────────────────────────────────────────────────┤
│                     Data Layer                          │
│  расы · биомы · предметы · здания · технологии · лут    │
├─────────────────────────────────────────────────────────┤
│                   Platform / Core                       │
│  файлы · ввод · сохранения · моды · аналитика           │
└─────────────────────────────────────────────────────────┘
```

### 2.1. Принципы

- **Симуляция не знает о рендере.** Обмен через события и снимки состояния.
- **Данные — снаружи.** Расы, предметы, здания, технологии, спавн-таблицы в JSON/CSV.
- **Детерминизм.** Один seed + одинаковый ввод = одинаковый мир.
- **Чанки.** Мир разбит на 32×32; обновление и сохранение по чанкам.
- **События.** Шина событий для UI, хроники, звука, достижений.
- **Моды.** Любая сущность может быть переопределена данными; скрипты — в песочнице.

### 2.2. Модель сущностей

- **ECS** (Entity-Component-System) или облегчённый actor-подход.
- Компоненты: `Position`, `Stats`, `Needs`, `AI`, `Inventory`, `Equipment`, `Combat`, `Family`, `VillageMember`, `Building`, `Animal`, `ParticleEmitter`.
- Системы: `TimeSystem`, `WorldSystem`, `NeedsSystem`, `AISystem`, `MovementSystem`, `CombatSystem`, `ReproductionSystem`, `EconomySystem`, `PoliticsSystem`, `TechSystem`, `ChronicleSystem`.

### 2.3. Пространственные структуры

- **Сетка чанков** для соседей и рендера.
- **Spatial hash** для поиска ближайших существ/еды/врагов.
- **Flow field** для массового пути (армии, миграции).
- **A\*** для индивидуальных маршрутов (дальние цели).
- **Очередь обновлений** для грязных клеток.

### 2.4. Производительность

| Система | Бюджет |
|---|---|
| Симуляция | ≤ 20 мс/кадр при 10k существ |
| Рендер | ≤ 8 мс/кадр |
| UI | ≤ 2 мс/кадр |
| Память | ≤ 2 ГБ |
| Загрузка мира 512² | ≤ 10 с |
| Сохранение | ≤ 2 с (в фоне) |

**Приёмы:** LOD, инстансинг, пул объектов, отложенные обновления, многопоточность (jobs), SIMD где доступно, кэш путей, «сон» далёких существ.

## 3. Данные и моддинг

### 3.1. Формат

```
/data
  /races        human.json, elf.json ...
  /biomes       forest.json ...
  /items        weapons.json, armor.json ...
  /buildings    buildings.json
  /tech         stone.json, bronze.json ...
  /spawn        spawn_tables.json
  /events       events.json
  /names        name_generators.json
  /localization ru.csv, en.csv ...
```

### 3.2. Схема (пример расы)

```json
{
  "id": "elf_forest",
  "name": "Лесные эльфы",
  "base": { "hp": 80, "power": 40, "wisdom": 80, "magic": 78, "speed": 1.05, "lifespan": 140, "fertility": 0.5 },
  "perks": ["genius", "long_lived", "magic_affinity", "lazy", "conservative", "fragile", "low_fertility"],
  "biomes": ["forest", "tropical_forest"],
  "techAffinity": { "magic": 1.3, "science": 0.9, "industry": 0.6 },
  "relations": { "human": 10, "orc": -10, "goblin": -20, "dwarf": 5 }
}
```

### 3.3. Моддинг

- **Уровень 1:** замена данных (новые расы, предметы, здания).
- **Уровень 2:** скрипты на встроенном языке (GDScript/C#/Lua) — события, ИИ, заклинания.
- **Уровень 3:** полные моды с ассетами.
- **Мастерская Steam**, загрузка модов, версионирование, конфликты.
- **Песочница:** скрипты не имеют доступа к файловой системе и сети.

## 4. Сохранения

- Формат: **бинарный снапшот + JSON-манифест** (версия, seed, дата, моды).
- Чанки сохраняются отдельно; при загрузке — потоково.
- Миграции версий (v1 → v2 → …).
- Автосохранение каждые 5 минут, 3 слота.
- Облачные сохранения (опционально).
- Экспорт мира в обмен (файл .aetheria).

## 8. QA

### 8.1. Автотесты

- **Юнит:** формулы боя, опыта, экономики, генетики.
- **Интеграция:** 1000 лет симуляции на 20 seed → нет крашей, население не уходит в 0/∞.
- **Детерминизм:** два прогона одного seed → одинаковый хеш состояния.
- **Сохранение:** save → load → save → идентичные данные.
- **Производительность:** 10k существ, 60 FPS, память ≤ 2 ГБ.

### 8.2. Ручные тесты

- Все кисти и катастрофы.
- Все этапы поселений.
- Все типы правления и переходы.
- Ядерная война и ядерная зима.
- Моддинг: установка, конфликты, удаление.
- Локализация: все языки, длинные строки, RTL.

### 8.3. Тест-планы

| Тест | Частота |
|---|---|
| Smoke (10 минут) | Каждый билд |
| Regression (2 часа) | Каждую неделю |
| Soak (8 часов) | Каждый месяц |
| Playtest (10 игроков) | Каждые 6 недель |
| Локализация | Перед релизом |
