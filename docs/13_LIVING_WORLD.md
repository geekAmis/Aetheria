# AETHERIA — Living World (как играть и что смотреть)

Документ описывает системы, добавленные в v0.10.0, и быстрые сценарии проверки.

## 1. Запуск

```
build\Aetheria.cmd
```

или

```
build\Aetheria.exe --main-pack build\Aetheria.pck
```

Полезные ключи:

| Ключ | Назначение |
|---|---|
| `--autostart` | сразу начать мир |
| `--seed N` | seed мира |
| `--size 128/256/512` | размер карты |
| `--genesis` | режим первородных |
| `--profile` | замер кадра с кистью |
| `--profile-idle` | замер без кисти |
| `--bench N` | ускорение 20× и отчёт N секунд |
| `--sim-years N` | быстро промотать N лет перед показом |
| `--shot PATH` / `--shot-delay S` | скриншот |

## 2. Живое существо

Выберите поселение, затем кликните по существу. В инспекторе видно:

- действие (`работает`, `охотится`, `строит`, `спит`, `идёт в поход`…);
- эмоцию и её причину (`голод`, `горе`, `гордость`…);
- переносимый предмет (туша, флаг, дерево);
- перки, навыки, семью, уровень;
- кнопки бога: исцелить, благословить, напугать, наградить, бессмертие, перк,
  избранное.

### Сценарий «охота → туша → еда»

1. `--autostart --seed 12345 --size 256 --bench 10`.
2. Дождитесь поселения с охотником (лес/саванна).
3. Кликните по существу с действием «охотится».
4. Оно идёт к животному, наносит удар, берёт тушу и несёт к поселению.
5. На складе появляется еда, у существа — «ест» и «радость».

## 3. Стройка

- Поселение выбирает здание и площадку.
- До 3 лучших по craft взрослых становятся строителями, лидер — прорабом.
- Строители идут к площадке, машут молотком, прогресс растёт от их числа.
- Без строителей прогресс почти останавливается.
- По завершении в хронике есть имена.

## 4. Эмоции и реакции

| Эмоция | Причина | Видимая реакция |
|---|---|---|
| радость | еда, рождение, благословение | иконка, лёгкий шаг |
| печаль | ранение, голод, низкое настроение | опущенная поза |
| гнев | война, осада | красная иконка |
| страх | молния, бомба, смерть рядом | бегство |
| голод | satiety < 25 | оранжевая иконка, поиск еды |
| гордость | охота, стройка, экспедиция | зелёная иконка |
| горе | смерть лидера/близкого | синяя иконка, траур |

## 5. Бог

- Точечные действия — в карточке существа.
- Создание народов и животных — вкладка «Мир» → «+ Существо» / «+ Животное».
- Созданное существо появляется в точке под курсором и сразу открывается в инспекторе.
- Бессмертный не умирает от старости, но может погибнуть физически.

## 6. Genesis

Включите «Genesis» в меню нового мира или запустите с `--genesis`.

- На старте нет хижин и ферм — только костёр.
- 6–9 первородных на племя: высокие статы, перки, уникальные имена.
- Первые дома, фермы и лесопилки строит AI.
- В хронике: «Первородный … зажигает первый костёр», затем первые постройки.

## 7. Дороги и экспедиции

- Поселения «знакомятся», когда находятся ближе 55 клеток.
- Знакомые пары строят дорогу: сегменты видны на карте, расходуется дерево.
- По готовой дороге торговля приносит золото, марш и переноска быстрее на 18%.
- Экспедиция 2–4 агентов выходит с флагом, открывает поселения, возвращается;
  события пишутся в хронику.

## 8. Производительность

```
Godot --path game --autostart --size 512 --profile
```

Ожидаемый результат на Ryzen 7 7435H / RTX 4060 Laptop:

```
[profile] frames=180 p50=14.3ms p95=18.0ms max=31.0ms fps_avg=70
[profile] PASS p95<=20ms max<=33ms
```

Если появился `FAIL`, в логе будет список медленных кадров с разбивкой
`sim` / `terrain` / `nature` / `creature` / `hud` / `roads`.
