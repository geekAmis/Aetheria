# 02. Ядро симуляции: мир, время, биомы, силы бога, катастрофы

## 1. Модель мира

| Параметр | Значение | Комментарий |
|---|---|---|
| Размер карты | 512×512 клеток (по умолчанию) | До 1024×1024 в настройках |
| Клетка | 2×2 м | Дерево выше человека в 3–4 клетки |
| Высота рельефа | 0…512 м | Хранится как 16-бит целое |
| Глубина воды | 0…64 м | Отдельный слой, не входит в рельеф |
| Чанк | 32×32 клетки | Единица LOD, сохранения и обновления меша |
| Слои клетки | рельеф, вода, тип почвы, влажность, температура, растительность, ресурсы, постройка, радиация | 9 слоёв |
| Сезон | 4 сезона по 30 дней | Влияет на урожай, миграции, отопление |

### 1.1. Генерация мира (порядок)

1. **Тектоника:** 3–6 плит, границы → горные хребты, разломы, вулканы.
2. **Эрозия:** гидравлическая и ветровая, 200 итераций → долины, каньоны, дельты.
3. **Климат:** широта + высота + удалённость от океана → температура; ветры → влажность.
4. **Гидрология:** сток воды, реки, озёра, болота, водоносные слои.
5. **Почвы и биомы:** по температуре, влажности, высоте, уклону.
6. **Ресурсы:** рудные жилы, уголь, нефть, уран, золото, соль, глина.
7. **Флора и фауна:** по несущей способности биома.
8. **Колыбели цивилизаций:** 4–8 стартовых племён.
9. **Валидация:** связность суши, наличие пресной воды, отсутствие тупиковых биомов.

**Гарантии генератора:** минимум 40% суши, минимум 2 реки на континент, минимум 3 биома, минимум 1 горный массив, стартовые племена не ближе 24 клеток друг к другу.

### 1.2. Слои и данные клетки

```
Cell {
  height: u16            // 0..512 м
  water:  u16            // 0..64 м
  waterType: u8          // нет / пресная / солёная / лава / кислота / радиоактивная
  soil:   u8             // тип поверхности (см. биомы)
  moisture: u8           // 0..255
  temperature: i16       // °C × 10
  vegetation: u8         // 0..255 биомасса
  resource: u8           // тип залежи
  resourceAmount: u16
  buildingId: u32        // 0 = нет
  radiation: u8
  ownerVillage: u32
  flags: u16             // выжжено, заражено, удобрено, затоплено...
}
```

## 2. Время и скорости

| Параметр | Значение |
|---|---|
| Базовый тик | 50 мс реального времени; **1 тик = 1 игровой час** |
| Игровые сутки | 24 тика = 1,2 с реального времени на 1× |
| Игровой год | 8 760 тиков = 438 с ≈ 7,3 мин на 1× |
| Скорости | 0 (пауза), 1×, 2×, 5×, 10×, 20× |
| Год на 10× | ~44 с |
| Год на 20× | ~22 с |
| Жизнь 70 лет на 10× | ~51 мин |
| Жизнь 70 лет на 20× | ~25 мин |
| Цель «костёр → атом» | 250–350 игровых лет ≈ 1,5–2 ч на 20× |

**Важно:** при ускорении шаг симуляции увеличивается, а частота «размышлений» ИИ снижается пропорционально (см. бюджет ИИ). Движение существ при шаге > 100 мс разбивается на подшаги, чтобы не проходить сквозь стены.

### 2.1. Календарь

- 4 сезона: Весна / Лето / Осень / Зима (по 91–92 дня).
- День/ночь: 16 ч света, 8 ч тьмы. Ночью падает зрение людей, растёт активность гоблинов, нежити, хищников.
- Лето: +урожай, +жажда, +пожары. Зима: −урожай, +голод, +смертность, миграции на юг.
- Праздники и религиозные даты — из культуры поселения.

### 2.2. Возраст и поколения

- Возраст хранится в годах с дробной частью.
- Младенчество: 0–3 года; детство: 4–12; юность: 13–17; взрослый: 18–55; старик: 56+.
- Дети не работают, не воюют, но учатся (+XP к навыкам).
- Старики теряют силу и скорость, но дают бонус к мудрости и обучению.

## 4. Силы бога

### 4.1. Рельеф

| Кисть | Эффект | Радиус | Ограничения |
|---|---|---|---|
| Поднять / опустить | ±1…20 м за мазок | 1…32 | Нельзя поднять выше 512 |
| Сгладить | усреднение высот | 2…24 | — |
| Песок | почва = песок, растительность = 0 | 1…16 | — |
| Равнина | почва = луг | 1…16 | — |
| Лес | почва = лес + деревья | 1…24 | Только на суше |
| Холм | высота +40…120 м, почва = холм | 2…16 | — |
| Гора | высота +150…300 м, почва = гора | 2…12 | — |
| Непроходимая гора | высота +300…450 м, флаг «непроходимо» | 1…8 | Нельзя ставить на воду |
| Трава: 5 видов | меняет текстуру и плодородие | 1…24 | — |
| Биом | полная перекраска биома | 2…32 | Стоимость «маны бога» |
| Вода: отмель / река / озеро / океан | вода = 1 / 3 / 8 / 20 м | 1…32 | Затопляет постройки |
| Осушить | вода = 0 | 1…32 | — |
| Лава | почва = лава, урон всему | 1…16 | — |
| Плодородие | vegetation +50% | 2…16 | — |
| Рудная жила | размещает ресурс | 1…8 | — |

### 4.2. Жизнь

- Посадить дерево / куст / цветы / грибы.
- Засеять поле (пшеница, рис, кукуруза, картофель, виноград, хлопок, лён).
- Заспавнить животное (выбор из бестиария).
- Заспавнить существо (раса, пол, возраст, уровень, перки).
- Создать семью / племя / поселение.
- Благословить: +здоровье, +плодородие, +мудрость, +удача.
- Проклясть: болезни, бесплодие, безумие, нежить.

### 4.3. Цивилизация

- Дать ресурсы поселению.
- Открыть технологию.
- Назначить лидера / свергнуть лидера.
- Разжечь войну / заключить мир.
- Наслать пророка / чудо.
- Создать катастрофу (см. ниже).

### 4.4. Стоимость и баланс

У бога есть «Эссенция» (0…1000), которая восстанавливается со временем. Дешёвые кисти — 1–5, катастрофы — 20–200, ядерный удар — 500. В песочнице эссенция бесконечна (отключается в настройках).

| Смерч | 2–6 клеток, движется | 10–40 с | 20–80/с, поднимает существ | Разрушение зданий, разброс предметов | Пыль, обломки, вихрь |
| Молния | 1 клетка | мгновенно | 80–150 | Пожар, гибель | Вспышка, искры, дым |

| Засуха | 10–40 | 60–365 дней | 0 | −урожай, +жажда, миграции | Пыль, сухая трава |
| Наводнение | 10–30 | 30–90 с | 30 | Затопление низин | Вода, грязь |
| Эпидемия | поселение | 30–120 дней | 5–20% населения | Карантин, смерть, иммунитет | Зелёные точки, туман |
| Голод | поселение | до конца запасов | смерть | Бунты, миграция | — |
| Мороз / метель | 10–40 | 30–120 с | 10/с | Гибель урожая, обморожения | Снег, ветер |
| Проклятие нежити | 10–30 | 60 с | — | Появление нежити | Тёмный туман |

### 5.1. Ядерная эра

- **Ядерный удар:** кратер, уничтожение зданий в радиусе, мгновенная гибель существ, ожоги на границе.
- **Радиоактивное облако:** дрейфует по ветру 3–10 игровых дней, заражает клетки.
- **Радиация:** −здоровье, мутации (новые перки), бесплодие, гибель урожая.
- **Ядерная зима:** при ≥ 20 ударах — глобальное похолодание на 10 игровых лет, −50% урожая, миграции к экватору.
- **MAD:** ИИ-государства с ядерным арсеналом отвечают ударом на удар; игрок может отключить в песочнице.

## 6. Система частиц

| Тип | Кол-во | Материал | Физика |
|---|---|---|---|
| Огонь | до 3000 | аддитивный спрайт | подъём, затухание, искры |
| Дым | до 2000 | мягкий спрайт, alpha | подъём, ветер, расширение |
| Пыль / обломки | до 2000 | спрайт + куски | гравитация, отскок |
| Дождь | до 4000 | линии | падение по ветру |
| Кислота / лава | до 2000 | капли | падение, разбрызгивание |
| Снег | до 3000 | точки | дрейф |
| Магия | до 1500 | аддитивные руны | орбита, пульсация |
| Кровь / грязь | до 1000 | спрайт | короткий импульс |
| Радиация | до 500 | мерцающие точки | хаотичное движение |

**Бюджет:** 12 000 активных частиц, 2 draw call (аддитивный и обычный). Обновление на GPU, спавн на CPU. Отключаемый «лёгкий режим» — 2000 частиц.

## 7. Порядок тика симуляции

```
1. Время: календарь, сезоны, погода
2. Мир: климат, эрозия, рост растительности, распространение огня/радиации
3. Катастрофы: движение и урон
4. Существа: потребности → восприятие → решение → движение → действие
5. Бой: расчёт попаданий, урона, смерти
6. Размножение и генетика
7. Инвентарь и предметы (подбор, износ, бафы)
8. Поселения: производство, потребление, стройка, налоги
9. Политика: отношения, решения лидеров, войны, дипломатия
10. Технологии: накопление очков, открытия
11. Религия и культура: вера, праздники, искусство
12. События и хроника
13. Рендер-очередь: обновление мешей, партиклов, UI
```

**Правило детерминизма:** при одинаковом seed и одинаковых действиях игрока мир развивается одинаково. Все случайности — через seeded PRNG с сохранением состояния.

## 8. Уровни детализации (LOD)

| Уровень | Условие | Что симулируется |
|---|---|---|
| L0 | В кадре, близко | Всё, каждый тик |
| L1 | В кадре, далеко | Потребности, движение, бой — упрощённо |
| L2 | Вне кадра | Потребности раз в 5 тиков, без анимации |
| L3 | Другой конец карты | Статистическая модель, раз в 50 тиков |

**Бюджет производительности:** 20 мс на симуляцию, 8 мс на рендер, 2 мс на UI при 60 FPS.

## 9. Режимы игры

| Режим | Описание |
|---|---|
| Песочница | Бесконечная эссенция, все кисти, все катастрофы |
| Творение | Ограниченная эссенция, цель — довести цивилизацию до космоса |
| Испытание | Сценарии: «Переживи чуму», «Построй империю», «Не допусти ядерной войны» |
| Наблюдатель | Никакого вмешательства, только камера и хроника |
| Мод-режим | Пользовательские правила и данные |
