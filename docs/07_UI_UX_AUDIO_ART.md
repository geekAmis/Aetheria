# 07. UI/UX, арт-дирекшн, аудио и локализация

## 1. Принципы UX

1. **«Бог не кликает по 200 кнопкам».** Любое действие — максимум 2 клика от основной панели.
2. **Мир на первом плане.** Интерфейс занимает ≤ 20% экрана в режиме наблюдения.
3. **Всё объяснимо.** Наведение на любую цифру показывает формулу и источник.
4. **Ошибки простительны.** Все действия отменяемы (Ctrl+Z), катастрофы можно «отмотать» в песочнице.
5. **Читаемость важнее красоты.** Силуэты, цветовые коды, слои.
6. **Один экран — одна задача.** Никаких вложенных меню глубже 2 уровней.

## 2. Информационная архитектура

```
Главное меню
├── Новая игра
│   ├── Генератор мира (сид, размер, климат, сложность)
│   └── Пресеты (Континент, Архипелаг, Пангея, Пустошь, Рай)
├── Загрузить

├── Настройки (графика, звук, управление, доступность)
```

## 3. Экраны и панели

### 3.1. Генератор мира

- Слайдеры: размер (256/512/1024), уровень океана, количество гор, лесов, пустынь, рек, ресурсов, стартовых цивилизаций.
- Пресеты: «Континент», «Архипелаг», «Пангея», «Мир-сад», «Пепел», «Случайный».
- Поле сида + кнопка «кубик».
- Предпросмотр мини-карты (2D) до старта.
- Кнопка «Сгенерировать» (3–10 с с прогресс-баром).

### 3.2. Левая панель — инструменты

Вкладки:

| Вкладка | Содержимое |
|---|---|
| **Рельеф** | поднять, опустить, сгладить, песок, равнина, лес, холм, гора, непроходимая гора, 5 трав, биомы |
| **Вода** | отмель, река, озеро, океан, осушить, лава |
| **Жизнь** | дерево, куст, цветы, грибы, поля, животные, существа, племя |
| **Катастрофы** | смерч, молния, дождь, кислота, лава, бомба, ядерная бомба, граната, метеорит, землетрясение, цунами, вулкан, пожар, засуха, наводнение, эпидемия, мороз |
| **Цивилизация** | ресурсы, технология, лидер, война, мир, пророк, чудо |
| **Благословения** | здоровье, плодородие, мудрость, удача, проклятия |

**Общие элементы:** размер кисти (1–32), сила (1–10), «ластик», «отменить», «повторить», подсказка с ценой в эссенции.

### 3.3. Правая панель

- **Инспектор** — карточка выбранного объекта.
- **Хроника** — лента событий с фильтрами.
- **Миникарта** — слои, границы, маркеры.
- **Слои** — рельеф, вода, температура, влажность, ресурсы, радиация, границы, дороги.
- **Статистика** — население, ресурсы, эпоха, счастье, экология.

Аналогично — карточки здания, поселения, животного, предмета.

### 3.5. Панель поселения

- Название, этап, население, лидер.
- Ресурсы: дерево, камень, еда, железо, золото (с трендом ↑↓).
- Производство/потребление по ресурсам.
- Здания (список, состояние, апгрейд).
- Роли совета.
- Отношения с другими поселениями.
- Кнопки: «Помочь ресурсами», «Дать технологию», «Назначить лидера», «Объявить войну».

### 3.6. Дерево технологий

- Горизонтальная лента эпох, узлы с иконками.
- Цвет: открыто / доступно / в процессе / заблокировано.
- Тултип: стоимость, эффект, требования.
- Поиск.

### 3.7. Карта дипломатии

- Цвета государств, границы, союзы, войны.
- Клик по государству → карточка.
- Таймлайн истории границ.

## 5. Онбординг

1. **Первый запуск:** 60-секундная заставка «ты — бог».
2. **Туториал-сценарий:** сгенерированный маленький остров, 3 задания:
   - поднять гору;
   - создать реку;
   - зажечь молнию и посмотреть, как племя тушит пожар.
3. **Подсказки:** контекстные, исчезают после 3 использований.
4. **Свободный режим:** туториал можно пропустить.
5. **Советы в загрузке:** «Кислотный дождь убивает урожай, но не вредит каменным зданиям».

## 6. Доступность

- 3 цветовые схемы для дальтонизма (протанопия, дейтеранопия, тританопия).
- Масштаб UI 80–150%.
- Крупный шрифт, контрастный режим.
- Переназначение всех клавиш.
- Пауза при потере фокуса.
- Отключение тряски камеры, вспышек, частиц.
- Субтитры для ключевых событий.
- Режим «без крови» (стилизованные искры вместо крови).
- Поддержка экранных дикторов для меню.

## 7. Арт-дирекшн

### 7.1. Стиль

- **2.5D изометрия / наклонная перспектива.**
- Низкополигональные объёмы с мягким освещением, без фотореализма.
- Палитра: тёплые землистые тона + насыщенные акценты биомов.
- Силуэты: деревья — конусы/шары, горы — гранёные пирамиды, существа — капсулы с цветом расы.
- Вода — полупрозрачная, с бликами и пеной.
- Снег, пепел, радиация — отдельные слои поверхностей.

### 7.2. Масштаб

- 1 клетка = 2 м.
- Дерево = 3–6 клеток в высоту.
- Гора = 15–40 клеток.
- Дом = 2×2 клетки, 1–2 в высоту.
- Замок = 6×6, 4 в высоту.
- Небоскрёб = 4×4, 12 в высоту.

## 9. Аудио

### 9.1. Музыка

- **Адаптивная система:** 4 слоя (бас, гармония, мелодия, перкуссия), включаются по контексту.
- **Эпохи:** камень — флейты, барабаны; бронза — струнные; средневековье — лютня, хор; индустрия — медь, марш; современность — синтезатор, оркестр; атом — тревожные струнные, электроника.
- **Биомы:** лес — деревянные духовые; пустыня — уд, перкуссия; горы — горны, эхо; океан — струнные, шум волн.
- **Расы:** у каждой лейтмотив (эльфы — арфа, орки — барабаны, дворфы — низкие рога, гоблины — скрипки-пиццикато).
- **События:** война — быстрый ритм; катастрофа — диссонанс; мир — пастораль.

**Реализация:** вертикальные стемы, кроссфейд 2–4 с, приоритет по «напряжённости» (0–100).

### 9.2. SFX

- Кисти: мягкий «шлепок» земли, всплеск воды, шелест травы.
- Строительство: стук молотка, пила.
- Бой: лязг, выстрелы, крики (стилизованные).
- Катастрофы: гром, взрыв, ветер.
- Животные: мычание, рык, пение птиц.
- UI: клики, наведение, открытие панелей.
- Бог: низкий гул, эхо, хор при чуде.

### 9.3. Голос

- «Голос бога» — низкий, обработанный, 30–50 реплик.
- Ключевые события — короткие фразы на «языке мира» (вымышленный).
- Полная озвучка не планируется.

## 10. Локализация

- Все строки — во внешних таблицах (CSV/JSON).
- Плюрализация, падежи, местоимения.
- Шрифты с поддержкой кириллицы, CJK, арабского (RTL).
- Тестирование на 11 языках.
- Культурные адаптации: имена, праздники, архитектура (опционально).

---

## 11. Производительность UX

- Загрузка мира: прогресс-бар с этапами (тектоника, климат, жизнь).
- Первые 3 секунды — интерактив (камера), даже если симуляция ещё грузится.
- Автосохранение каждые 5 минут, без фризов (в фоне).
- Ограничение частиц и теней в настройках.
- Режим «потоковая передача» — упрощённая графика для стримеров.
