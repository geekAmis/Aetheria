# 05. Предметы, инвентарь, ресурсы, крафт, здания и экономика

## 1. Инвентарь

### 1.1. Модель

| Параметр | Значение |
|---|---|
| Базовые слоты | 12 |
| Слоты рюкзака | +6 / +12 / +24 (малый / средний / большой) |
| Вес | `capacity = 20 + powerLevel * 0.4 + backpackBonus` кг |
| Перегруз | скорость −30%, нельзя бежать, +усталость |
| Стаки | еда, ресурсы, стрелы — до 20/50/100 |
| Быстрый доступ | 4 ячейки на панели |

### 1.2. Слоты экипировки

| Слот | Что можно надеть |
|---|---|
| Голова | шлем, шапка, капюшон, корона, диадема |
| Лицо | маска, очки, вуаль |
| Шея | амулет, ожерелье, шарф |
| Торс | кираса, бронежилет, рубаха, роба, мантия |
| Спина | плащ, рюкзак, крылья (полудраконы) |
| Руки | перчатки, наручи |
| Ноги | портки, поножи, штаны, юбка |
| Ступни | сапоги, ботинки, сандалии |
| Основная рука | меч, топор, копьё, лук, арбалет, ружьё, посох |
| Вторая рука | щит, кинжал, второй пистолет, факел, книга |
| Пояс | фляга, кошель, ножны, инструменты |
| Кольца | 2 кольца |

### 1.3. Свойства предмета

| Свойство | Описание |
|---|---|
| `id`, `name`, `icon` | Идентификатор и отображение |
| `category` | оружие / броня / еда / книга / ёмкость / рюкзак / инструмент / украшение / магия |
| `weight` | Вес, кг |
| `durability` | 0…100%, изнашивается |
| `quality` | Плохое (×0.8) / Обычное (×1.0) / Хорошее (×1.2) / Мастерское (×1.5) / Легендарное (×2.0) |
| `rarity` | Обычный / Необычный / Редкий / Эпический / Легендарный |
| `buffs` | Список модификаторов |
| `debuffs` | Список штрафов |
| `slots` | Куда надевается |
| `value` | Базовая цена |
| `requirements` | Уровень, сила, навык |

## 7. Экономика поселения

### 7.1. Производство и потребление

```
производство = Σ(здания × рабочие × навык × сезон × технологический множитель)
потребление  = население × (еда 1 + вода 1 + товары 0.3)
излишек      = производство − потребление
```

- Голод: если еды < 0 — сначала едят скот, затем умирают.
- Склад: 500 ед. на амбар, 2000 на склад.
- Порча: еда −2%/день без амбара, −0.5% с амбаром.

### 7.2. Цены

```
цена = базоваяЦена × (1 + дефицит/100) × (1 − избыток/150) × (1 + жадность торговца)
```

- Дефицит: потребление > производство.
- Торговый путь: +10% к цене за каждую клетку расстояния.
- Война: +50% к цене оружия, −30% к цене еды.

### 7.3. Налоги и содержание

- Налог: 10–30% от дохода жителей.
- Содержание армии: 1 золото/воин/день.
- Содержание зданий: 0.5–5 золота/день.
- Коррупция: растёт с размером государства; снижается судами и грамотностью.

### 7.4. Торговля

- Караваны между поселениями (по дорогам), корабли (по воде).
- Товары: излишки → продажа, дефицит → закупка.
- Торговые соглашения: +20% скорость, −10% цены.
- Контрабанда: при войне, риск потери товара.

### 7.5. Бедность и богатство

- Жители делятся на бедных / средних / богатых.
- Богатые платят больше налогов, но требуют предметов роскоши.
- Неравенство > 60 → риск бунта.
- Бунт: потеря ресурсов, поджоги, смена лидера.
