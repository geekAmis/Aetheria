# AETHERIA

**Живой мир-аквариум / god simulator.** Создай континент, зажги первый костёр и досмотри историю от каменного века до атомной эры — или не допусти её.

Игра написана на **Godot 4.7.2** (GDScript). Симуляция, мир и интерфейс генерируются кодом; никаких сторонних 3D-моделей и текстур не требуется.

---

## Как запустить

### Готовый билд (без установки)

```
D:\PC-game\build\Aetheria.cmd
```

или напрямую:

```
D:\PC-game\build\Aetheria.exe --main-pack D:\PC-game\build\Aetheria.pck
```

`Aetheria.exe` — это Godot 4.7.2 runtime, `Aetheria.pck` — упакованные ресурсы игры. Папку `build` можно переносить целиком.

### Из проекта (для разработки)

```
D:\PC-game\tools\godot\Godot_v4.7.2-stable_win64.exe --path D:\PC-game\game
```

Или открой `D:\PC-game\game\project.godot` в Godot 4.7.2.

## Что уже играется

- **Процедурный мир** 128 / 256 / 512 клеток: тектоника, горы, эрозия, реки, озёра, климат, 21 биом, ресурсы, флора и фауна. Один seed = один и тот же мир.
- **7 разумных видов**: люди, лесные эльфы, дворфы, орки, гоблины, ящеролюды, полудраконы — со своими статами, долголетием, плодовитостью, именами и архитектурой.
- **Симуляция жизни**: потребности, голод, жажда, здоровье, настроение, рассудок, старение, смерть, пары, беременность, рождение детей, наследование статов, уровни и перки.
- **Поселения**: лагерь → деревня → город → мегаполис. Строят дома, поля, лесопилки, шахты, амбары, рынки, храмы, библиотеки, стены, фабрики, ракетные шахты. Добывают, производят, торгуют, платят налоги, голодают, бунтуют.
- **Технологии**: 8 эпох и 48 технологий, от огня до термояда. Эпоха наступает, когда поселение открывает 4 технологии.
- **Политика и война**: отношения, союзы, войны, осады, разграбление, колонии, смена лидеров, пророки и чудеса. ИИ сам объявляет войны и заключает мир.
- **Экология**: животные размножаются, мигрируют, охотятся и становятся добычей; лес растёт, пожар распространяется, радиация и ядерная зима меняют мир.
- **Силы бога**: рельеф, вода, леса, молнии, смерчи, метеориты, бомбы, ядерные удары, землетрясения, потопы, вулканы, засухи, метели, эпидемии, благословения, проклятия, пророки, чудеса, новые племена и целые цивилизации.
- **Интерфейс**: инспектор существ/поселений/клеток, летопись с фильтрами, миникарта, слои (биомы/высота/температура/влажность/ресурсы/радиация), дерево технологий, кодекс, настройки, сохранения, обучение.
- **Атмосфера**: день/ночь, звёзды, рассветы, дождь, снег, пепел, туман, огни поселений, низкополигональный арт, процедурная эмбиент-музыка и синтезированные звуки катастроф.
- **Сохранения**: 1 автослот + 3 ручных слота, JSON-снапшоты.

```
D:\PC-game\
  game\                 проект Godot
    data\               JSON-данные: расы, биомы, животные, здания, технологии, силы
    scripts\core\       мир, симуляция, агенты, поселения, хроника, сохранения
    scripts\world\      рендер мира, природа, поселения, существа, эффекты, камера, небо

  tools\assetfinder\    утилита поиска CC0-ассетов
```

## Лицензия и моды

Проект **закрытый**: существующие основные файлы (`game/scripts`, `game/data`,
`game/scenes`, `game/assets`, `build`, `docs`) изменять, удалять и пересобирать
нельзя. При этом разрешено **добавлять новые файлы и новые функции** в виде
аддитивных модов:

- данные через `mods/<имя_мода>/data/*.json`;
- новые функции/UI через `mods/<имя_мода>/mod.gd`;
- новые ассеты в `mods/<имя_мода>/assets/`;
- расположение: рядом с игрой, в `%APPDATA%\Godot\app_userdata\Aetheria\mods`
  или в `game/mods` при запуске из проекта.

Мод не должен требовать правки ядра, подменять существующие файлы или
критически ломать базовую сборку/сохранения. Подробности: `LICENSE`,
`CODE_POLICY.md`, `MODDING.md`.

## Данные и моддинг

Всё содержимое — внешние JSON в `game/data`. Чтобы добавить расу, биом, животное, здание или технологию, достаточно отредактировать JSON и перезапустить игру. Симуляция читает данные через `DataStore` и не зашивает контент в код.

### Пересборка `.pck`

```powershell
cd D:\PC-game\game
D:\PC-game\tools\godot\Godot_v4.7.2-stable_win64_console.exe --headless --path . `
  --export-pack "Windows Desktop" D:\PC-game\build\Aetheria.pck
```

## Технические заметки

- Движок: **Godot 4.7.2** (Forward+, GDScript).
- Мир по умолчанию 256×256 клеток (512 м), до 512×512.
- Симуляция детерминирована seed'ом; все случайности идут через `RandomNumberGenerator`.
- Рендер: чанки 32×32, vertex-color low-poly, MultiMesh для деревьев и существ, GPU-частицы для эффектов.
- Симуляция отделена от рендера: `WorldModel`/`SimWorld` не знают о сцене и общаются сигналами.
- Производительность: ~100 FPS на RTX 4060 при 80–250 существах и 20×; узкие места — GDScript-циклы симуляции.

## Известные ограничения

- Это **играбельный вертикальный срез / песочница**, а не финальный AAA-релиз: нет мультиплеера, полной озвучки, 10 000 существ и всех 50+ животных из ТЗ.
- Английская локализация покрывает данные и часть интерфейса; русский язык — основной.
- Экспортные шаблоны Godot не скачались в этой среде, поэтому билд запускается через runtime-бинарник Godot с `.pck` (это не редактор, а обычный запуск игры).
