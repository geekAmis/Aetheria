# Политика разработки и использования кода Aetheria

**Статус:** закрытый проект. Правообладатель: geekAmis.
**Лицензия:** `LICENSE` (proprietary / all rights reserved).
**Движок:** Godot 4.7.2 (MIT) — см. `game/THIRD_PARTY.md`.

## 1. Главное правило

Существующие основные файлы игры **заморожены**. Разрешены:
- добавление **новых** файлов;
- новые функции в новых файлах;
- моды-надстройки поверх штатных точек расширения.

Запрещены изменение, удаление, переименование, перезапись или подмена
существующих основных файлов. Мод не должен критически ломать базовую сборку.

## 2. Что считается основными (существующими) файлами

- `game/project.godot`, `game/scenes/**`
- `game/scripts/**`
- `game/data/**`
- `game/assets/**` (оригинальные ассеты и шейдеры)
- `build/**` (готовые сборки; их можно запускать, но нельзя изменять,
  пересобирать под видом официальных или подменять)
- `docs/**`, `README.md`, `LICENSE`, `CODE_POLICY.md`, `SECURITY.md`,
  `MODDING.md`, `game/THIRD_PARTY.md`

## 3. Что разрешено

1. Запускать игру и играть.
2. **Добавлять новые файлы** (скрипты, сцены, данные, ассеты, UI, локализацию)
   в отдельные каталоги:
   - `mods/<имя_мода>/` рядом с игрой/проектом;
   - `user://mods/<имя_мода>/` (папка пользователя);
   - `%APPDATA%\Godot\app_userdata\Aetheria\mods\...` в Windows-сборке.
3. Реализовывать **новые функции** в новых файлах Мода, если они не требуют
   правки ядра.
4. Добавлять новые данные через `mods/<имя>/data/*.json`; загрузчик объединяет
   массивы по `id` (эпохи — по `name`).
5. Добавлять новые скрипты через `mods/<имя>/mod.gd` (точка входа, необязательная
   функция `setup(game)`); загрузчик подключает их после создания HUD.
6. Распространять бесплатные Моды, если они:
   - не содержат основных файлов игры;
   - не выдают себя за официальный контент;
   - не используются для коммерческой продажи доступа к игре;
   - не ломают базовую сборку и сохранения.

## 4. Что запрещено

1. Изменять, удалять, переименовывать, перезаписывать, патчить или подменять
   **существующие** основные файлы.
2. Подменять ядро Модом, внедрять код в основные файлы, модифицировать runtime
   или обходить защиту.
3. **Критически ломать билд**, в том числе:
   - делать базовую игру неспособной запуститься без Мода;
   - повреждать сохранения базовой игры;
   - отключать критические проверки безопасности;
   - вызывать падение/бесконечный цикл на старте;
   - требовать модификации ядра для работы Мода.
4. Распространять игру или её основные файлы от своего имени.
5. Продавать игру, Моды, доступ к ним или выдавать себя за правообладателя.
6. Удалять уведомления об авторских правах и лицензии.
7. Загружать в репозиторий секреты, токены, ключи, cookies, дампы памяти,
   пользовательские сохранения и другие чувствительные данные.

## 5. Технический контракт аддитивных Модов

```
mods/
  my_mod/
    mod.gd          # extends Node; func setup(game) -> void
    README.md       # необязательно
    data/
      races.json    # необязательно
      techs.json    # необязательно
      ...
    assets/         # новые ассеты Мода (необязательно)
```

- `mod.gd` — новый файл, не изменяет ядро. Пример:

```gdscript
extends Node

func setup(game) -> void:
    game.hud.toast("Мой мод загружен", "tech")
```

- `setup(game)` получает `GameSession`; Мод может добавлять свои узлы,
  подключаться к сигналам, создавать UI и новые системы.
- Ошибки в Моде не должны ломать базовую игру. Загрузчик пропускает
  некомпилируемые файлы с предупреждением.
- После удаления Мода базовая игра обязана запускаться и работать.
- Мод не может записывать/перезаписывать файлы ядра.

## 6. Правила репозитория

- Ветка по умолчанию: `main`.
- Запрещены force-push в `main` и переписывание истории.
- Секреты и локальные данные не коммитятся; см. `.gitignore`.
- Большие бинарники — только через Git LFS (`build/Aetheria.exe`).
- Любой контрибьютор обязан соблюдать `LICENSE` и эту политику.

## 7. Безопасность

- Не публикуйте токены GitHub, `.env`, ключи, cookies и пароли.
- Если секрет попал в репозиторий — немедленно отзовите его и очистите историю.
- Файл `docs/GITHUB_DATA.md` содержит учётные данные и **не должен** попадать
  в Git (он исключён через `.gitignore`).
- Подозрительные файлы и уязвимости сообщайте правообладателю приватно.

## 8. Ответственность

Нарушение политики прекращает право использования. Правообладатель вправе
требовать удаления копий и защищать свои права доступными законом способами.
